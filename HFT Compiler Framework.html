Validity certificate: guard boxes per regime

A kernel runs only when all three features fall inside its box; anything else falls back to the full baseline model. Boxes are quantile intervals fitted on the calibration split.

Coverage level changes what can be removed

At 99% the boxes are wider, so fewer comparisons are provably constant: calm loses all "always no" eliminations and volatile loses all "always yes" ones.
